# Signature Verification Subtle Failure

This example demonstrates how a subtle, unintentional change to signed data can cause digital signature verification to fail, even when both parties are honest. It highlights the critical importance of data integrity throughout the signing and verification process, illustrating a common source of "mysterious failures."

## Language

`python`

## How to Run

Save the code as main.py and run from your terminal:
python main.py
